# House-and-Estate-Dashboard-

Structure of Dashboard 

The House Property Sales Analysis Dashboard is an interactive data visualization project designed to 
analyze real estate property sales, pricing trends, property distribution, and location-based performance.

The project uses a housing dataset sourced from Kaggle to explore important factors affecting
property prices, including living area, number of bedrooms, floors, property condition, and ZIP code.

🎯 Project Objectives:
  Analyze overall house sales performance and pricing trends.
  Identify high-value ZIP codes and locations.
  Understand the relationship between living area and property prices.
  Compare property prices based on the number of bedrooms.

⭐ Key Features

1. 📈 KPI Overview
 
  The dashboard provides five important performance indicators:

  ◦ Total Properties: 5K
  
  ◦ Total Sales: 3BN
  
  ◦ Average Price: 551.96K
  
  ◦ Median Price: 460.94K
  
  ◦ Average Price per Sqft: 265.88
  
  ◦ These KPIs provide a quick overview of the overall housing market performance.
  
2. 📅 Interactive Filters

 Users can dynamically explore the dataset using filters:

  ◦Sales Date – Analyze sales across different time periods.
 
  ◦Plot by ZIP Code – Compare property performance by location.
 
  ◦Bedrooms – Filter properties based on bedroom count.
 
  ◦Floors – Analyze properties based on the number of floors.
 
 
3. 💰 Price vs. Living Area

  ◦Analyzes the relationship between property living area and average price. 
  
  ◦Helps identify how property size influences property value.
  
  ◦Uses a scatter plot to visualize pricing patterns across different living areas.
  
 
4. 📉 Trend of Price
 ◦Tracks property price movements over time.
 ◦Highlights price fluctuations and major peaks.
 ◦Helps understand changes in housing market performance.
 
5. 📍 Average Price by ZIP Code
 ◦Identifies high-value locations.
 ◦Compares average property prices across ZIP codes.
 ◦Helps investors identify premium real estate locations.
 
6. 🛏️ Bedrooms by Price
 ◦Compares property prices across different bedroom categories.
 ◦Identifies bedroom categories with higher average property prices.
 ◦Helps understand how property configurations relate to pricing.
 
7. 🏘️ Properties by Distribution
  Categorizes properties into different price ranges:

   $300K–$500K
 
   $500K–$750K
 
   Under $300K
 
   $750K–$1M
 
   $1M+
 
   This visualization helps understand the distribution of properties across different market segments.
 

8. 🏠 Condition by Properties
 ◦ Analyzes property distribution based on condition ratings.
 ◦ Identifies the most common property condition.
 ◦ Helps understand the overall quality distribution of available properties.

🔍 Key Business Insights
 Based on the dashboard, the following insights can be observed:

 ⋅ strong Property Market: The dataset contains approximately 5,000 properties with total sales of around 3 billion. 
 
 ⋅ Average vs. Median Price: The average property price is 551.96K, while the median is 460.94K, suggesting that higher-priced properties influence the average.
 
 ⋅ Premium Location: ZIP code 98039 records the highest displayed average price at approximately 2.05M.
 
 ⋅ Price Distribution: The $300K–$500K category contains the largest number of properties, with approximately 1,633 properties.
 
 ⋅ Bedroom Analysis: Properties with 8 bedrooms show an average price of approximately 1.16M in the dashboard.
 

💡 Problems Solved

 This project addresses several challenges in real estate data analysis:
 
 ◦ Lack of Market Visibility: Provides a consolidated view of property sales and pricing performance.
 ◦ Difficulty Comparing Locations: Helps identify expensive and affordable ZIP codes.
 ◦ Unclear Pricing Patterns: Makes it easier to understand how living area and bedrooms relate to property prices.
 ◦ Complex Data Interpretation: Converts raw housing data into understandable charts and KPIs.
 
 
🛠️ Tools & Technologies

  Dataset: Kaggle – House Property Sales Dataset
  Data Visualization: Power BI
  Data Analysis: Exploratory Data Analysis (EDA)
  Dashboard Design: Interactive charts, KPI cards, slicers, and filters
